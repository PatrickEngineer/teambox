# TeamBox

Веб-приложение для управления проектами и задачами, разработанное в рамках выпускной квалификационной работы.

## О проекте

TeamBox представляет собой клиент-серверное веб-приложение, предназначенное для управления проектами, задачами и совместной работы пользователей. Проект разработан в рамках исследования методов обеспечения безопасности программ и данных веб-приложений.

В ходе разработки были реализованы механизмы аутентификации и авторизации пользователей, ролевая модель доступа, управление проектами и задачами, работа с комментариями и файлами, а также REST API для взаимодействия между клиентской и серверной частями приложения.

Кроме практической реализации веб-приложения, проект использовался в качестве основы для разработки лабораторного практикума по анализу и исследованию уязвимостей веб-приложений.

## Реализованный функционал

* регистрация и аутентификация пользователей;
* JWT-аутентификация;
* ролевая модель доступа (RBAC);
* управление проектами;
* управление задачами;
* управление комментариями;
* загрузка файлов;
* REST API;
* документация Swagger UI.

## Технологический стек

Backend:

* Python

Frontend:

* HTML

## Запуск проекта

Установка зависимостей

pip install -r requirements.txt

## Настройка базы данных

Необходимо создать PostgreSQL-базу данных и указать параметры подключения в файле .env.

Пример:

DATABASE_URL=postgresql://user:password@localhost:5432/teambox_db
SECRET_KEY=your_secret_key

## Запуск приложения

uvicorn app.main:app --reload

После запуска документация API будет доступна по адресу:

http://localhost:8000/docs

## Назначение проекта

Проект разработан в учебных и исследовательских целях для изучения вопросов безопасной разработки веб-приложений, механизмов контроля доступа и методов защиты программ и данных.
